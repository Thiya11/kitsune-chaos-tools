# Contributing to Kitsune Chaos Tools

First of all, thank you for considering contributing to Kitsune Chaos Tools ❤️

Kitsune Chaos Tools is an open-source initiative focused on creating modern, interactive STEM experiences for physics, electronics, mathematics, and creative technical learning — accessible to everyone and free forever.

We welcome:
- Bug fixes
- Performance improvements
- Accessibility enhancements
- UI/UX improvements
- New simulations/tools
- Documentation improvements
- Educational ideas and discussions

---

# Development Philosophy

We aim to build tools that are:

- Interactive
- Visually engaging
- Educational
- Lightweight
- Accessible
- Open and community-driven

Please keep user experience, readability, and learning value in mind when contributing.

---

# Before You Start

Before working on large changes, please open:
- an Issue
- or a Discussion

This helps avoid duplicated work and allows us to discuss architecture and design decisions beforehand.

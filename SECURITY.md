# Security Policy

## Supported Versions

Kitsune Chaos Tools is currently under active development.

Security updates are generally applied to the latest version of the project.

---

## Reporting a Vulnerability

If you discover a security vulnerability, please report it responsibly.

Please avoid creating public GitHub issues for security-related concerns.

Instead, contact:

contact@kitsunechaos.com

Please include:
- a description of the issue
- steps to reproduce
- potential impact
- screenshots or proof-of-concept if applicable

We will make a best effort to:
- acknowledge reports promptly
- investigate the issue
- provide updates when appropriate
- resolve confirmed vulnerabilities as quickly as possible

Thank you for helping keep the project and community safe.
